# Arquivo de artefatos

Esta pasta é destinada a cópias históricas exportadas do projeto, como manifests
de publicação, relatórios validados, screenshots de diagnóstico e versões de
Excel. Não guardar aqui:

- `.env`, chaves, cookies ou perfis Chromium;
- modelos locais em uso;
- arquivos de entrada necessários ao ciclo atual;
- backups sem data/origem identificável.

Use nomes com data e origem, por exemplo:
`2026-10-03-manifesto-publicacao.json`.
